gsf 0.1.0 is the first release of gsf. gsf rips the music of Game Boy Advance games to GSF, the PSF-family format for Game Boy Advance music. A set contains the game's cartridge image, cut down to what the music reads, and a small stub that starts one song. A GSF player emulates the console and runs the game's sound driver. The music then plays as it does in the game.

`gsfrip` runs on Windows 10 or later and requires no runtime DLLs. For macOS, the README explains how to build from source.

## Features

- **Ripping.** `gsfrip game.gba` finds the game's sound driver and writes a `.gsflib`, a `.minigsf` for each song and a playlist. The library is named after the cartridge's product code, and each mini after its place in the set and its title. `--list` lists the songs, and `--only` rips the songs whose names match.
- **Drivers.** `gsfrip` rips games with AlphaDream's driver, Logik State's GBAModPlay, Nintendo R&D1's and R&D2's drivers, Quintet's driver and MP2K, the sound driver of Nintendo's SDK. The README lists the games that each driver supports.
- **The stub.** The stub replaces the game's start-up code. It makes the calls that the game makes to set up its sound driver, starts the song whose number the mini stores, and runs the driver once a frame as the game does.
- **Trimming.** Each song runs on a model of the console, and the library keeps only the bytes of the cartridge that some song reads, with the cartridge's header and the stub. The other bytes are zeros. The model doesn't run the DMA transfers at the blanks or for the sound FIFOs. `gsfrip` therefore counts those that read the cartridge, fails if the trim would cut what they certainly read, and warns of what it can't see. `--no-trim` keeps the whole image.
- **Lengths.** `gsfrip` reads each song's commands for its length: two passes of the loop and a fade of 10 s, or the end of the song and a fade of 1 s for its last notes. A song that plays no notes gets no mini.
- **Tags.** Each mini has its title, the game, the length and the fade, and the artist, the date, the copyright, a comment, `gsfby` and `tagger` where they're known or given. The library has no tags. For Aero the Acro-Bat: Rascal Rival Revenge, the set gets the game's name, the composer and arranger, the developer and publisher, the date of the first release, and a title for each song that names where the game plays it. The options `--game`, `--artist`, `--year`, `--copyright`, `--by` and `--tagger` replace them.

## Aero the Acro-Bat: Rascal Rival Revenge

`gsfrip` rips the European and the US releases. The set has every module of the game's music. The game's code plays all but one of them: in the story of the intro, the title screen, the card that names each act, the pause menu, the game over, the ending, and the levels. One module is in the image, but no code plays it, and one module has a part that the game skips. Both come last in the set, as unused songs.

The European release was checked in mGBA 0.11. Each song of the set plays the same trimmed and untrimmed. For each song, the game's code and the set played it from the title screen for its whole length, and the sound that the driver mixed for the Direct Sound channels came out the same, apart from the frames in which the title screen pauses the driver. The title of each song that the game plays names where the game played it. The sets weren't checked on the console itself.

The US release has the same modules and samples, with the driver at another address. Its set had the same checks before the European one, on a sample of the songs.

## Known limitations

- A song plays as its commands give it. What a game's code changes while a song plays, such as a fade or a track that it mutes, stays out.
- With MP2K, `gsfrip` doesn't rip games that set a song up in their code before they start it, or games with Camelot's version of the driver.
- gsf has no player. The sets play in the GSF players that exist.
- Players can differ in level. Aero the Acro-Bat switches the sound off and on after it sets up its driver, and the stub does the same. mGBA 0.11 then plays the Direct Sound channels at half volume, and some other players don't.
