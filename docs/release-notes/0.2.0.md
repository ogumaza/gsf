`gsfrip` runs on Windows 10 or later and requires no runtime DLLs. For macOS, the README explains how to build from source.

## Hugo: The Evil Mirror

`gsfrip` rips the US release. ITE Media's driver plays 4-channel modules from one bank in the cartridge. Each song of the bank that has patterns becomes a song of the set, and each plays at the music volume that the game sets for it. A song that loops gets two passes and a fade of 10 s. A jingle that ends plays out to its last sound, with a fade of 1 s. The audio of the game's videos isn't ripped.

The set gets the game's name, the composers, the developer and publisher, the date of the first release, and a title for each song that names where the game plays it. The minis are numbered in the order in which a player first hears the songs in the game.

The set was checked in mGBA 0.11. Each song plays the same trimmed and untrimmed. The game's code and the set sent the same bytes to Direct Sound channel A over the start of each song that loops and the whole of each jingle. The sets weren't checked on the console itself.

## Known limitations

- In the game, the music that a jingle interrupts comes back after the jingle's last row and cuts the jingle short. The set plays each jingle on its own, to its last sound.
- A song plays as its commands give it. What a game's code changes while a song plays, such as a fade or a track that it mutes, stays out.
- With MP2K, `gsfrip` doesn't rip games that set a song up in their code before they start it, or games with Camelot's version of the driver.
- gsf has no player. The sets play in the GSF players that exist.
