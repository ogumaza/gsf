gsf 0.3.0 rips six more games: Mother 3, Golden Sun: The Lost Age, Fire Emblem: The Sacred Stones, The Legend of Zelda: A Link to the Past & Four Swords, Sword of Mana and Magical Vacation. MP2K games whose code sets the driver's sound mode now rip as the game plays them.

`gsfrip` runs on Windows 10 or later and requires no runtime DLLs. For macOS, the README explains how to build from source.

## New games

- Sword of Mana, the US release, and Magical Vacation play their music on Brownie Brown's driver. Each sound that uses the music's channels is a song. The sound effects aren't ripped.
- The Legend of Zelda: A Link to the Past & Four Swords has two drivers. Nintendo R&D2's driver plays A Link to the Past, and MP2K plays the menus and Four Swords. `gsfrip` rips a set for each, in the folders `A Link to the Past` and `Four Swords`. Each folder has its library, minis and playlist.
- Golden Sun: The Lost Age has Camelot's version of MP2K. Each song plays through Camelot's sound module, as in the game.
- Fire Emblem: The Sacred Stones sets some songs up before it starts them, with another number of channels. Other MP2K games set a reverb or a volume this way. The sets now make the same calls as the game.
- Mother 3 fills the cartridge's 32 MiB, with no padding at the end for the stub. In such an image, the stub now goes in the longest run of zeros or of 0xFF bytes.

## Changes to existing sets

- Some MP2K games change the driver's sound mode after they set the driver up: the sample rate, the number of channels, the master volume or the reverb. The sets now make the same changes. Rips of those games differ from those of gsf 0.2.0 and play as the game does.
- `gsfrip` keeps one record of the cartridge's reads for the whole set, in place of one for each song. Games with many songs now rip with much less memory.

The sets were tested in mGBA 0.11. Each trimmed set was compared with the untrimmed one, and a sample of each game's songs with the game itself. The sets weren't tested on the console.

## Known limitations

- Mario Tennis: Power Tour has Camelot's version of MP2K too, and `gsfrip` doesn't rip it yet. `gsfrip` names the reason.
- `gsfrip` has no song titles or tags for the new games yet. Their minis are named by song number. `--game`, `--artist`, `--year` and `--copyright` set the tags.
- A song plays as its commands give it. What a game's code changes while a song plays, such as a fade or a track that it mutes, stays out.
- gsf has no player. The sets play in the GSF players that exist.
