gsf 0.4.0 moves each mini's song number into the cartridge's header, so that every mini's address follows the GSF description for games of any size. It also fixes a song of Rhythm Tengoku that played wrongly in a trimmed set, and can rip the sound effects of A Link to the Past, Sword of Mana and Super Robot Taisen A, D, R and J.

`gsfrip` runs on Windows 10 or later and requires no runtime DLLs. For macOS, the README explains how to build from source.

## New

- `--effects` adds a game's sound effects to its set, after the music, where `gsfrip` can start them as the game does: The Legend of Zelda: A Link to the Past (160 sound effects, 21 of them unused by the game), Sword of Mana, the US release (595), and Super Robot Taisen A (128), D (157), R (124) and J (161). Each is named `Effect N`. A sound effect plays alone, and most get their end as their length. A rip without `--effects` has the music alone, as before.

## Changes to existing sets

- Each mini now stores its song's number as two bytes at 0x080000BE, the reserved bytes at the end of the cartridge's header that its complement check leaves out. Until 0.3.0, the number was a word of the stub. In a game of 16 MiB or more, the stub can lie at 0x09000000 or above, and the minis' addresses then started with 0x09. The GSF description asks for the high byte of the entry point, 0x08. The minis now meet it whatever the game's size. Every set's files change. Don't mix files of a set from an earlier version with those of a new set.
- In Nintendo R&D1's games, the library keeps the whole of each instrument record and sample header that a song reads part of. In Rhythm Tengoku in mGBA, the order of the interrupts made the driver read a field of an instrument record that `gsfrip`'s model of the console didn't, and one song played differently trimmed and untrimmed.

## Other fixes

- The check of the timed DMAs that read the cartridge now follows the console: a source in the cartridge always counts up, whatever the DMA's settings say. No game that `gsfrip` rips is affected.
- `gsfrip` refuses a rip whose music reads the cartridge's first word or the bytes where the song's number goes. The set replaces them.

The sets were tested in mGBA 0.11. Trimmed sets were compared with untrimmed ones, and a sample of each game's songs with the game itself. The sets weren't tested on the console.

## Known limitations

- Mario Tennis: Power Tour has Camelot's version of MP2K, and `gsfrip` doesn't rip it yet. `gsfrip` names the reason.
- `gsfrip` has no song titles or tags for most games yet. Their minis are named by song number. `--game`, `--artist`, `--year` and `--copyright` set the tags.
- A song plays as its commands give it. What a game's code changes while a song plays, such as a fade or a track that it mutes, stays out.
